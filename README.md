
🌍 Travel Ecommerce Website
A full-stack Travel Ecommerce Website where users can explore destinations, book travel packages, and manage their trips. Designed to offer a seamless browsing and booking experience, the site runs locally on http://localhost:8080.

🚀 Features
Browse featured travel destinations with images and descriptions

Search and filter holiday packages by location, price, and category

Add packages to cart and proceed to booking

User authentication (login/signup)

Admin panel for managing listings and bookings

Responsive UI for desktop and mobile

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript 

Backend: Node.js & Express.js

Database: MongoDB 

Server: Runs on localhost:8080
